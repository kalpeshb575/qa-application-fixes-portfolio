
# QA Application Fixes & Testing Portfolio

## About This Portfolio

This repository contains sanitized QA work samples demonstrating real-world software testing and application troubleshooting activities.

The focus is on application installation, uninstallation, upgrade validation, troubleshooting, root cause analysis, defect investigation, and fix verification.

> Note: All examples are sanitized and contain no confidential company information, customer data, credentials, or proprietary source code.

## QA Areas Covered

- Application Installation Testing
- Application Uninstallation Testing
- MSI and EXE Installer Testing
- Silent Installation & Uninstallation
- Installation Parameter Validation
- Upgrade Testing
- Exit Code Analysis
- Windows Application Troubleshooting
- WinGet Application Testing
- Root Cause Analysis
- Regression Testing
- Defect Validation
- File and Registry Validation
- Reboot and Restart Scenarios

## Work Sample Format

Each application issue is documented using the following approach:

**Problem → Investigation → Root Cause → Fix → Test Validation → Result**

## Sample Categories

### Application Installation Fixes

Examples covering installation failures, silent installation parameters, installer behavior, and installation validation.

### Application Uninstallation Fixes

Examples covering uninstall command generation, MSI/EXE uninstall behavior, application-running scenarios, parameters, and cleanup validation.

### WinGet Fixes

Examples covering application detection, upgrade behavior, remediation issues, and repeated upgrade scenarios.

### QA Validation

Examples demonstrating test scenarios, regression validation, expected vs actual results, and verification of application fixes.

## Testing Approach

For each fix, the validation focuses on:

1. Reproducing the issue
2. Analyzing logs and application behavior
3. Identifying the root cause
4. Validating the implemented fix
5. Performing positive and negative testing
6. Performing regression testing
7. Verifying the final application state
